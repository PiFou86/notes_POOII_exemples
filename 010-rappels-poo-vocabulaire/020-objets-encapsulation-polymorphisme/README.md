# CH01-E02 — Objets, encapsulation, héritage UI et polymorphisme

Source : `chapitres/010-rappels-poo-vocabulaire.tex`. Type : console autonome.

Le scénario distingue deux objets ayant leur propre identité et leur propre
état. Il distingue aussi l'invariant du solde, la précondition d'un dépôt et sa
postcondition. Enfin, il protège une collection, limite l'héritage à une
variation de présentation et parcourt plusieurs animaux par leur abstraction.

```bash
dotnet build RappelsPoo.csproj
dotnet run --project RappelsPoo.csproj
```
