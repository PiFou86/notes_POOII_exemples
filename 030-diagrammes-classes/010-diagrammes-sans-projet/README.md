# CH03-E01 — Diagrammes UML sans projet artificiel

Les sources se trouvent sous `uml/classDiagrams/05-diagrammes-classes/`. Elles
sont reliées aux explications et au code du chapitre 030. Aucun projet C# n'est
créé lorsque le diagramme illustre uniquement une relation; les exemples de
classes qui réapparaissent dans le code sont compilés dans leur chapitre
conceptuel correspondant.
