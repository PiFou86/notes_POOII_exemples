# CH15-E01 — Commandes Git et fichiers de démonstration

Ce chapitre enseigne un outil, pas une API C#. Les commandes restent des
extraits textuels dans les notes afin d'éviter un projet artificiel. Les petits
fichiers utilisés pour illustrer un conflit ou `.gitignore` doivent rester près
de l'explication qui les emploie et ne jamais contenir de secret réel.
