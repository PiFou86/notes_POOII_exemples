# CH16-E01 — Extraits destinés à la revue de code

Les violations commentées du chapitre sont conservées comme texte et ne sont
pas incluses dans un projet compilé. Leur rôle est de pratiquer les niveaux
`[Bloquant]`, `[Important]`, `[Suggestion]`, `[Question]`, `[Félicitation]` et
`[Détail]`. Une version corrigée ne devient un projet autonome que si son
exécution apporte une valeur distincte de la discussion de revue.
