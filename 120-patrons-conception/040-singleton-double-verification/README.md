# CH12-E04 — Trois implantations explicites du Singleton

L'exemple compare la création fainéante simple, le verrouillage à double
vérification et la création avide. Ces implantations explicites sont
volontairement conservées; elles ne sont pas remplacées par `Lazy<T>`.

```bash
dotnet run --project SingletonDoubleVerification.csproj
```
