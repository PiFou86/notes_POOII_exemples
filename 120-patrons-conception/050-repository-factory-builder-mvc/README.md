# CH12-E05 — Repository, Factory Method, Builder et MVC

L'exemple garde les responsabilités distinctes : Repository masque la source,
Factory Method laisse un créateur spécialisé choisir l'exporteur, Builder
construit un rapport étape par étape et le contrôleur MVC orchestre modèle et
vue sans porter la règle métier.

```bash
dotnet run --project PatronsApplicatifs.csproj
```
