# CH02-E01 — Classe abstraite, interface et composition

Source : `chapitres/020-abstractions-interfaces-polymorphisme.tex`. Type :
console autonome.

L'exemple réunit les trois décisions du chapitre sans les confondre : `Forme`
partage un concept et impose une opération, `IExportable` exprime une capacité,
et `Commande` possède des lignes par composition.

```bash
dotnet build AbstractionsComposition.csproj
dotnet run --project AbstractionsComposition.csproj
```
