# CH05-E01 — Types, tableaux, égalité, opérateurs et indexeur

Source : `chapitres/050-csharp-essentiel.tex`, notamment
`sec:csharp-surcharge-methodes`. Type : console autonome.

Le scénario vérifie l'effet d'une copie de valeur et d'une copie de référence,
les index et plages d'un tableau, l'égalité logique cohérente avec le hashcode,
la surcharge de méthodes, la redéfinition des opérateurs d'une
`MesureMetre`, l'indexeur validé d'une `Matrice` et les expressions de
traitement de `null`.

```bash
dotnet build CSharpEssentiel.csproj
dotnet run --project CSharpEssentiel.csproj
```
