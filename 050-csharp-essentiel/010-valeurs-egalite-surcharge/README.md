# CH05-E01 — Valeurs, références, égalité et surcharge

Source : `chapitres/050-csharp-essentiel.tex`, notamment
`sec:csharp-surcharge-methodes`. Type : console autonome.

Le scénario vérifie l'effet d'une copie de valeur et d'une copie de référence,
l'égalité logique cohérente avec le hashcode et la résolution des surcharges de
méthodes, y compris la conversion implicite d'un `int` vers `float`.

```bash
dotnet build TypesObjets.csproj
dotnet run --project TypesObjets.csproj
```
