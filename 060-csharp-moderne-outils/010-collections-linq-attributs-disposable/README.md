# CH06-E01 — Collections, lambdas, LINQ, validation et `IDisposable`

Source : `chapitres/060-csharp-moderne-outils.tex`. Type : console autonome.

Le scénario choisit plusieurs collections selon leur rôle, utilise `Func` et
`Action`, montre l'exécution différée, la recherche unique et la pagination
ordonnée avec LINQ, valide un objet avec `Validator` et libère une ressource
avec `using`.

```bash
dotnet build CSharpModerne.csproj
dotnet run --project CSharpModerne.csproj
```
